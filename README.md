# Valenbici-Smart
The smart way to move around Valencia. Smart ValenBici allows you to plan your bike routes and know in advance if there will be bikes or parking spots available at each station so you can commute without surprises.

Valenbici Smart is an interactive application developed entirely in Python. For the development of this application, two main phases were carried out. The first phase consisted of data processing and model training, and the second phase involved the development of the web application itself.
